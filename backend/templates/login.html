About Us

About VAANI

Bridging the communication gap through technology and compassion

VAANI

Voice of the Silent

VAANI is an assistive web-based platform designed to bridge the communication gap between the hearing and speech-impaired community and the wider society. The primary goal of VAANI is to make communication more inclusive by enabling users to practice and understand sign language using modern technology.

The platform focuses on learning, awareness, and accessibility rather than complex interactions. VAANI allows users to practice sign language, track their learning progress, explore NGOs working in the accessibility domain, and stay informed about community events and meetups.

By combining a simple user interface with a robust backend system, VAANI ensures that users can access meaningful information and learning resources without technical complexity. The project is built with scalability in mind and follows a clean separation between frontend and backend for better security and maintainability.

Features Provided by VAANI

1
Sign Language Practice

Users can practice sign language gestures. Each practice action is recorded to help users improve consistency and learning.

2
Learning History Tracking

Tracks how many times a user practices a sign. Displays messages like "You practiced HELLO 5 times" to encourage continuous learning.

3
NGO Information Portal

Displays a list of NGOs working for the hearing-impaired community. Read-only access promotes awareness and collaboration.

4
Events & Meetups

Shows events posted by NGOs including workshops, meetups, and awareness programs. No registration or payment required.

5
Sign Language Dictionary

Search-based dictionary for sign language words. Users can search for a word and view related sign information as a learning reference.

6
NGO Partnership & Reach-Out

NGOs can submit partnership requests through a form. Requests are stored securely for controlled onboarding after verification.

7
Responsive & Accessible Interface

Fully responsive design using Bootstrap. Works on desktop, tablet, and mobile with a simple layout and minimal cognitive load.
